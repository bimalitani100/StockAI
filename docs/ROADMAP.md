# Roadmap

## v0.1 — Foundation (current)

- Next.js + TypeScript interface
- FastAPI service and versioned endpoint
- End-to-end request with graceful failure state
- API tests, architecture, learning notes, and changelog

## Candidate next milestones

- **v0.2:** choose a licensed market-data provider; add configuration, caching, and symbol search
- **v0.3:** PostgreSQL persistence, migrations, watchlists, and portfolio transactions
- **v0.4:** authentication and per-user authorization
- **v0.5:** reproducible analytics and model-evaluation pipeline before predictive UI
- **Later:** containers, continuous delivery, and AWS after runtime and scale requirements are known

Versions are outcomes, not dates. This avoids pretending requirements are settled before we learn from the preceding slice.
